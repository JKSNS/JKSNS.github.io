# project_kraken

**Kraken: A Cascade CTF-Autosolver** · v0.2.5

A capture-the-flag auto-solver built around a cheapest-first cascade: deterministic tooling first, model reasoning only when computation runs out. A deterministic flag validator is the sole oracle. A closed-loop optimizer learns from every solve and re-orders the cascade.
